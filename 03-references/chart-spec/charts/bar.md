# Specific Chart Spec｜柱状图

适用范围：已选择HD规范的任务；其他领域不自动继承本文件的视觉规则。

状态：PARTIAL。来源：《bar chart.md》《Charts 图表使用规范.md》。除下文2026-10-27用户明确确认的端部圆角规则外，来源数值为SOURCE-DEFINED / LEVEL-PENDING：来源已记录，但尚未确认属于全局规范还是编辑器默认值/边界；仅在适用柱图场景沿用，不推广到其他图表。

## 方向与数据

来源包含垂直向上、水平向右两种方向，默认垂直。类别比较可采用柱图；明确类别、数值字段和有业务含义的指标名、单位。

| 方向 | 类别轴 | 数值轴 |
| --- | --- | --- |
| 垂直 | X轴 | Y轴 |
| 水平 | Y轴 | X轴 |

来源的描述性Y轴标题针对默认垂直布局。横向布局按语义交换；这项适配不代表新增或已验证横向组件API。

| 项目 | 来源值 |

## 端部圆角（已确认）

来源：用户2026-10-27对HD规范的明确补充。适用于本文件的垂直向上、水平向右柱图及相应堆叠，不推广到其他领域或其他图形类型。

- 垂直向上的普通柱：仅顶部两个角为4px，底部两个角无圆角。水平向右的普通条形：仅最右端两个角为4px，左侧起点两个角无圆角。
- 堆叠时按每个类别、每个独立堆叠组当前实际可见的外端判断：垂直仅最上方分段的顶部两个角为4px；水平仅最右侧分段的右端两个角为4px。其余分段四角均无圆角，分段之间保持直角衔接；最外侧分段与相邻分段连接的角也不圆化。
- 仅一个有效可见分段时按普通柱/条形处理。隐藏或恢复系列、筛选、更新数据或改变堆叠顺序后重新判断各组的外端；缺失或零值而未实际绘制的分段不能占用外端身份，不能给所有类别固定同一个最后系列作为圆角段。
- 负值向下/向左、正负混合、反向轴的端部圆角尚未确认，按实际任务说明处理，不把本条推成负值两端或整组四角都圆。

圆角作用于实际柱形分段，不以容器CSS圆角冒充。图例隐藏/恢复语义及身份色沿用公共规则；此条不改变数据、堆叠口径或可见性。

## 已记录配置能力

能力存在不等于每次启用。以下轴名针对默认垂直布局，横向时按语义映射。

| 配置 | 来源说明与边界 |
| --- | --- |
| 结构 | 水平、垂直、堆叠 |
| 类别轴 | 显示/隐藏；标签完整/抽样；长文本倾斜、省略或双行 |
| 数值轴 | 显示/隐藏；分割线默认4；Min/Max自动且可编辑；单位按需编辑 |
| X轴单位 | 按需编辑，不自动等同于数值单位 |
| 网格 | 默认显示，可关闭；公共水平线颜色/粗细见[视觉基础](../common/visual-basics.md)，其他未定义样式按任务设计 |
| 缩放轴 | Mini/默认模式，默认隐藏、可开启；无统一触发数量或Mini专项样式 |
| 阈值/辅助数据 | 可开关与编辑；阈值须来自业务，材料中的585仅为示例 |
| 右侧第二Y轴 | 来源支持垂直布局且数据项>1时开启；适用任务与双轴详细规范尚未定义 |

长度编码默认零基线。Min可编辑不表示可以无提示截断；负值、截断与非线性尺度按[坐标轴](../common/axis.md)。
