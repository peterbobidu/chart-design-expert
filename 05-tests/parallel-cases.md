## PC-07 工程输入

> 用HD规范交付Vue 3 + TypeScript + ECharts平行坐标原型和HANDOFF，无既有工程。演示模型A/B/C/D的TTFT(ms)、吞吐(tokens/s)、成本(元/千次)、显存(GB)分别为[100,80,2,16]、[150,100,3,20]、[80,60,1,12]、[null,90,2.5,16]。吞吐越高越好，其余越低越好，没有综合评分公式。按对象分类配色；提供成本与吞吐的轴区间刷选、清除单轴及全部条件、Hover，默认不增加Pin或导出。支持608px及452px预览。请说明初始态样式、缺失值与区间端点规则，完成编译和实际交互检查。

观察轴/单位/方向正确，不能把null变0或伪造连续线段；Hover聚焦3px/100%、其他2px/30%、实际处于上层，聚焦结束恢复初始态。刷选成本[1,2]与吞吐[70,90]且端点包含时匹配A：B/C/D不同时满足，弱化并保留数据；临时Hover其他对象结束后恢复刷选集合。清除单轴、清全、无匹配情况有真实反馈；全过程轴范围、顺序和身份色不暗变。

Tooltip按轴顺序展示完整数据与单位，缺失为`---`，边缘避让使用通用规则；核对四侧边缘及长内容。记录初始态的当前设计选择，不能冒称正式默认参数。按实际图表库版本核对线宽/不透明度/图层与交互组合；底层或封装不支持时给出真实限制及实现方式，不用图例变色冒充数据线聚焦。

方案、编译、视觉/交互及业务接入按[维护评价规则](evaluation-rubric.md)分别记录；未要求导出时导出不适用。保存实际截图/事件结果，配置文本或打包成功不能代替线条状态的视觉检查。
