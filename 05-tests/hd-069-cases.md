# HD 0.6.9 试跑用例

本文件保存输入与判据。用户反馈beta试跑未发现问题，逐案例证据范围见[验证记录](../VALIDATION.md)。后续回归时每例在新对话显式调用目标版本Skill，先只复制“输入”，不要把预期告诉模型。固定模型与设置；记录所用包版本、回答/工程入口、实际证据和偏差。规则问答通过不能替代代码或浏览器检查。

## 再测完整原型

每例新开对话。使用模拟数据并标记，不复用真实业务秘密。工程按实际宿主/默认交付规则生成，随包HANDOFF；若环境只能给方案，则记录工程/视觉未验证。

### HD069-07：指标与双尺寸

输入：

> 请用HD规范生成月度平均带宽柱图原型，Vue 3 + TypeScript + ECharts。数据为1月80、2月100、3月90 Mbps；上方指标为100 Mbps、名称“平均带宽”、环比上涨8%，均为演示数据。默认卡片尺寸，并提供452px宽预览方式。请交付可运行工程与HANDOFF。

检查：默认608px与452px实际容器宽度、24px内边距只出现一次、指标字号/颜色和4px/8px间距、字体真实回退、轴单位与指标单位分开、无裁切。新行高与高度如为设计建议有记录。图形风格的未定义项不声称正式合规。构建、视觉分开记录。

### HD069-08：真实分页与隐藏恢复

输入：

> 请用HD规范生成对比20条产线月产量的交互图表原型，用中性模拟数据。卡片452px，图例位置固定在底部。希望能查找各条产线并切换显示，交付工程和HANDOFF。

检查：底部实际放不下时有可操作分页；翻页前后数据可见性不变；点击某项只隐藏该系列、标记文字#DFDFDF，恢复原身份色；键盘可操作；重新排序或翻页不重新配色；轴范围选择有解释，不把分页当数据筛选。保留操作前后截图或日志证据。

### HD069-09：饼图与环形布局

输入：

> 用HD规范生成两个可切换的组成视图：普通饼图和环形图，演示类别A=40、B=30、C=20、D=10。饼图用右侧图例显示名称、值和占比；环形图用底部图例和中心总量，提供图例隐藏操作。请交付可运行工程，说明隐藏类别后的百分比与总量口径。

检查：饼图不强制中心数字；右侧列表与图形垂直居中，底部图例水平居中；占比与中心值口径明确、协调；中心字号/环宽/引导线未被冒称来源已定义。必要静态说明不依赖Hover。

## 领域边界回归

### HD069-10

输入：

> 半导体设备温度趋势图，采用半导体规范；外层宽度由业务容器决定。请给出标题、图例标记和内边距方案，本轮不生成工程。

预期：半导体标题16px/bold/24px、图例点10px、内容内距16px；不把HD新增24px、608px默认及关键指标样式自动套给半导体。

## 记录方式

逐例记录“通过 / 部分通过 / 失败 / 未验证”、具体偏差和证据位置；同会话静态推演不记成独立试跑通过。先跑01～06，再跑07～09工程，最后跑10；无需每次生成整套评测报告。发现偏差时保留原输入及输出，便于判断是规则缺口还是模型执行问题。
