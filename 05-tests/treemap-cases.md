# HD 矩形树图用例

本页是维护侧输入与判据，不进入上架运行包。规则源见[专项](../03-references/chart-spec/charts/treemap.md)。2026-10-20用户确认标题沿用HD通用20px/28px，单图深浅不混用数值和层级两种含义。

来源核对：用户SVG及Pixso节点4953:1的矩形圆角4px、无描边；图形内相邻块间距1px；文本HarmonyOS Sans SC / Regular / 14px / 22px / 白色。样例标题16px/24px被上述用户确认覆盖。来源色包括蓝#2070F3/#1F55B5、绿#87C859/#62B42E、紫#715AFB、青#2CB8C9；这些是样例色，不是完整数值色阶，也不扩充HD的25色分类色板。标签居中结合整体位置观察，不把文本节点的TOP行框对齐误读为块内顶对齐。

## TM-06 工程输入

> 用HD规范生成一个矩形树图交互原型，Vue 3 + TypeScript + ECharts。使用演示数据：A组（设备甲40、设备乙20、设备丙10），B组（设备丁18、设备戊8、设备己4）；金额单位万元。另提供包含长名称、小值0.2、真实零、缺失和负值的边界数据切换。面积表达金额；同组同色系，深浅仅表达金额，金额越大越深，在同组内比较；占比以全图有效金额总和为分母。提供608px和452px预览，块内只显示名称，Hover可看完整名称、金额和占比。不需要下钻。请交付工程和HANDOFF。

观察实际绘制的块圆角、间隙、居中标签及省略，检查长标签不串块、字体回退、稳定分组身份、深浅方向、原值/分母一致及异常数据处理说明；真实零不伪造成正面积，缺失/负值不通过绝对值或补零伪装成有效金额。核对图表库版本是否真实支持所选实现，不能把外壳CSS圆角当块圆角。不要求为了过验收增加未请求的导出或下钻。
